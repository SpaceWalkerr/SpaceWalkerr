## About Me

I build software that turns ideas into usable, reliable products. My work spans full-stack applications, AI/ML experiments, cloud deployments, automation workflows, and mobile-first user experiences.

I enjoy working at the intersection of engineering, product thinking, and real-world problem solving: designing systems that are clean enough to scale, simple enough to maintain, and useful enough for people to actually use.

- Building full-stack products with modern web and mobile technologies
- Exploring AI-assisted workflows, intelligent automation, and data-driven systems
- Designing APIs, dashboards, internal tools, and user-facing applications
- Focused on clean architecture, performance, maintainability, and practical impact

## Core Strengths

- **Full-Stack Engineering:** React, Angular, Node.js, Express, NestJS, databases, authentication, APIs, and deployment workflows
- **AI and Data:** Python, NumPy, Pandas, scikit-learn, TensorFlow, PyTorch, data visualization, and model-driven applications
- **Mobile and Cross-Platform:** React Native, Kotlin, mobile UI patterns, and backend-integrated app experiences
- **Cloud and Deployment:** AWS, Google Cloud, Firebase, Vercel, Netlify, Render, Cloudflare, and production-ready delivery
- **Product Mindset:** Building tools that are practical, usable, and aligned with real user needs
